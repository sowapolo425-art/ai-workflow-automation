处理流程

Webhook 输入 · SQLite 持久化 · 可选 LLM

01 / RECEIVE接收客户邮件唯一编号防止重复处理
02 / CLASSIFY分类与优先级显式标注模型或规则模式
03 / EXTRACT提取客户需求每条需求关联邮件原文证据
04 / DRAFT生成回复草稿保存待审核，不自动发送
05 / NOTIFY通知销售工作台模拟通知，保留记录
